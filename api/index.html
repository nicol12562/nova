Nova Chat Planes Admin API

API de Nova

Documentación de endpoints y ejemplos de uso

Endpoints Disponibles

GET
/api/users Obtener lista de usuarios
POST
/api/users Crear nuevo usuario
GET
/api/planes Listar planes disponibles
POST
/api/planes/subscribe Suscribirse a un plan
POST
/api/feedback Enviar feedback
GET
/api/chat Obtener historial de chat

Ejemplo de Uso

curl -X GET "https://api.nova.com/api/users" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Respuesta:
{
  "_users": [
    { "id": 1, "name": "Juan", "email": "juan@ejemplo.com" },
    { "id": 2, "name": "María", "email": "maria@ejemplo.com" }
  ]
}
